# 第一编 · 邦联宪制基础

## K-1.1 国家性质

全称：幽燕渤海邦联共和国 / Yan-Bohai Confederate Republic 简称：燕渤联盟 / 邦联民国 / 幽燕 政体：邦联制 + 议会共和制（两院制）+ 民兵—纳税人限定选民门槛 时代背景：大洪水后的后中华秩序时代

## K-1.2 法统来源

法统不来自人民主权的原始授权（拒绝雅各宾式宪法创制传统）；

法统来自历史积淀与习惯法传承；

三大精神宪制资源（思想底座，非立法直接来源）：

希伯来经典法律传统（Torah）；

列奥·施特劳斯自然正当理论；

中华古典周制。

## K-1.3 立法机构（两院制 · 邦权与法团双轨）

### K-1.3.1 总纲

邦联立法机构合称 稷下会盟院（Jixia Council of the Confederate Houses），名称典出战国稷下学宫与封建邦国会盟传统。但其内部为 严格的两院制，并非现代西方意义上的"国会"或"议会"。

立法权配置之根本前提：

拒绝现代西方大众民主的一院制普选；

拒绝按总人口分配席位的雅各宾式比例代表；

立法权来源于 地缘主权（邦权） 与 法团力量（钱与枪） 的双轨结晶；

制度蓝本：**1787** 年美国邦联—制宪时期 + 神圣罗马帝国诸侯大会 + 荷兰联省共和国三级会议。

### K-1.3.2 上议院 · 邦君院（Senate of the Confederate States）

正式名称：稷下会盟院·上议院 / 邦君院 / 参议院

代表性质：地缘主权的绝对平等代表

八邦 + 稷门联邦特区 在该院的席位 绝对平等（建议每邦/特区 3 席），不论人口、面积、财力差异；

此种平等是 邦权（**State Sovereignty**）的物理体现，不可由邦联中央以任何"现代化"理由削减。

产生方式：

由各邦内部最高权力机构（各邦土豪议会、长老会、邦君会议）直接任命 或 间接选举；

上院议员对其所属邦的主权机关负责，不对个人选民负责；

任期与召回程序由各邦自行依本邦习惯法规定。

核心职权：

外交、宣战、媾和、缔约的绝对否决权——任何对外重大行动须上院多数通过；

修宪绝对否决权——任何修宪须上院全体邦一致或超级多数同意；

总理（首席执政官）提名权——见 K-1.4.2；

历史权利法庭法官任命的同意权；

疆界争端、跨邦水权、海域划界事项的最终裁断权。

类比：

1787 年美国参议院（每州 2 席的封建契约平等）；

神圣罗马帝国诸侯大会（Reichstag der Fürsten）；

现代瑞士联邦州院（Ständerat）。

### K-1.3.3 下议院 · 法团院（House of Estates and Free Burghers）

正式名称：稷下会盟院·下议院 / 法团院 / 自由民院

代表性质：维系本邦秩序的"钱与枪"——法团主义代表，非按人口的一人一票比例代表。

席位分配原则——由维持社会运转的实体组织获得席位：

永平邦矿业护卫队 + 矿业法团；

稷门特区航运公会、商团武装；

中山邦铁路商团、行会；

保定邦宗族联合会、水利会社；

辽西邦防务承包人协会、港口公会；

沧海邦盐业公会、渔业行会；

邺邦过境贸易商会、漳河水文协会；

上谷邦边境巡逻队、互市商团、游牧特许部落代表；

燕山邦大学共同体、文化遗产法团、防务智库。

各邦下院席位数量参照下列复合公式核定（具体比例由邦联宪制起草委员会另订）：

邦联税收贡献度（钱袋）；

民兵服役在册名额（武德）；

核心法团登记规模（组织化的自发秩序）。

绝对禁止：

❌ 按总人口比例分配席位；

❌ 流民、未在民兵名册者、不缴邦联税者享有该院选举权或被选举权。

核心职权：

预算与税收法案的专属创制权——一切邦联财政预算、税收、关税法案 必须由下院首先提出（出钱者支配钱袋的封建铁律）；

内阁信任投票权——见 K-1.4.2；

下院议员对其所代表的法团负责，可由该法团依内部章程随时召回；

对外条约的财政条款审议权（条约的政治条款属上院专管）。

类比：

1787 年美国众议院（"钱袋专属创制权"原型）；

荷兰联省共和国三级会议（City Burghers + Nobility + Clergy 法团结构）；

中世纪英格兰下议院的早期形态（Borough + Knight 代表制）。

## K-1.4 邦联行政体制（议会制 + 双重制衡）

### K-1.4.1 政体定性

邦联政体为 议会共和制——行政权由立法机构产生，政府首脑对议会负责。但 不照搬英国式单院议会制，而是与两院制结构进行 双重制衡的缝合：行政权同时受制于 上院的邦权约束 与 下院的钱袋制约。

绝对拒绝：

❌ 美国式总统制（拥有独立民意基础与行政实权的强势元首）；

❌ 半总统制（双首长制下的人民直选总统）；

❌ 任何意义上的全国普选行政首脑制度。

### K-1.4.2 邦联执政委员会 / 内阁的产生

首脑职衔：邦联首席执政官（President of the Confederate Council） / 邦联总理。

产生程序——上院提名，下院通过：

|     |     |     |
| --- | --- | --- |
| 步骤  | 主体  | 行动  |
| 1\. 提名 | 上议院（邦君院） | 经各邦协商，提名邦联首席执政官人选及其内阁名单 |
| 2\. 信任投票 | 下议院（法团院） | 对上院提名行使信任投票；多数通过方可就任 |
| 3\. 就任 | 邦联首席执政官 | 主持邦联执政委员会（邦联内阁），对两院共同负责 |

制度逻辑：

上院提名 = 防止人口/财力大邦（稷门、燕山）通过法团联盟控制中央，霸凌边疆邦（辽西、上谷）；

下院通过 = 防止上院以邦权之名脱离财政与武装现实，搞空中楼阁式集权；

两院双重锁 = 任何执政团队都必须是 八邦地缘利益的妥协产物 **\+** 法团钱袋的实质同意。

#### K-1.4.2a 首席执政官行政实权清单

修订理由（邦联宪制起草委员会与稷下会盟院政策研究局联署核定）：

原 K-1.4.2 之产生程序——上院提名、下院通过——构成双重锁结构，迫使首席执政官必须同时是八邦地缘平衡与各法团财力的交集点。此结构在平时为分权制衡，在危机时则为集体失能。瑞士联邦委员会主席制度即前车之鉴——主席职位事实上仪式化，七委员分割日常政务。1781—1787 年间美国邦联完全无行政首脑，致谢斯起义无人镇压，终于逼出 1787 年制宪。

邦联制天然有行政软化之弊。若令邦联运转，首席执政官须具实权，至少含下列三项独立行政权：

|     |     |     |
| --- | --- | --- |
| 项目  | 权能内容 | 制衡机制 |
| **①** 内阁部长独立任命权 | 首席执政官得不经事先协商，独立任命邦联各部部长 | 下院于 60 日内行使事后审查权，得以多数否决任命；上院仅对外交部长、防务部长保留同意权 |
| **②** 邦联核心职能行政令签署权 | 就邦联两项核心职能（共同防御、对外条约）签发行政令，无须逐案经两院通过 | 行政令须公告并送两院备案；上院得以三分之二多数撤销；任何行政令不得变更邦联—邦关系或选民资格 |
| **③** 紧急状态限时行政授权 | 战争、瓦房店化危机、大规模边境秩序崩溃等情形下，得请求两院授予最长 180 日之紧急行政权 | 参照德国《基本法》第115a 条「防卫情况」机制；授权须上院过半数与下院过半数双重通过；期满自动失效，不得连续授权 |

红线：

首席执政官仍由两院产生（依原 K-1.4.2 程序），不得引入直选元首；

上述行政实权不延伸至司法权——历史权利法庭独立性不可侵犯；

上述行政实权不延伸至各邦内政——财政、教育、司法、警察、文化政策仍归各邦（原 K-1.4.5）；

紧急状态期间，修宪、变更选民资格、变更八邦疆界之动议一律暂停。

类比：

德国《基本法》第 64 条（联邦总理对部长之任免权）；

美国宪法第二条第二款（总统任命权 + 参议院同意权之区分适用）；

德国《基本法》第 115a 条（防卫情况下之紧急权力）。

K-1.4.3 国家元首：虚位 + 轮值

不设拥有实权的国家总统；

邦联国家元首由 八邦与稷门特区代表（上议院议员或各邦邦长）每年轮值担任；

模式参照：瑞士联邦委员会主席（**Bundespräsident**）轮值制；

礼仪上象征邦联平等，实质上 杜绝任何人借元首之位搞中央集权复辟。

K-1.4.4 建设性不信任投票（Constructive Vote of No Confidence）

借鉴德国《基本法》第 **67** 条机制：

下议院如欲倒阁，不得仅投不信任票；

必须在提出不信任案的同时，选出新的邦联首席执政官人选；

防止各法团为争权夺利导致邦联行政频繁瘫痪。

### K-1.4.5 中央—邦关系

各成员邦保留高度自治权；

邦联层面仅负责两项：

共同防御（Mutual Defense）；

对外条约（Foreign Treaties）；

财政、教育、司法、警察、文化政策——均归各邦。

## K-1.5 司法体制

普通法 **/** 习惯法优先；

制定法仅用于补充与协调；

历史权利法庭（**Historical Rights Tribunal**）——专门处理疆界、族群过渡带、宗族遗产、跨邦水权等历史敏感事项，取代公投机制。

**D-03**（邺城—安阳跨漳河文化圈）——主权归幽燕，文化共管归豫；

**D-04**（沧州—德州过渡带）——以古黄河北流故道为水文边界裁定；

**D-07**（坝上草原归属）——历史权利法庭裁决 + 蒙古族牧业社区特许自治权。

## K-1.7 选民资格：民兵—纳税人双重门槛（凝结核选举权制度）

### K-1.7.1 法理前提

邦联拒绝建立在普遍人头之上的现代大众民主。理由如下：

大洪水后的诸夏地区为秩序洼地——若在缺乏自发秩序的土壤上施行无门槛的一院制普选，必然演化为多数人的暴政（**tyranny of the majority**），流氓无产者通过选票合法抢劫土豪财产，最终全社会瓦房店化。

政治权利的正当性来源不是出生，而是对共同体武德与财政的实质贡献。

自由的最初生长阶段，是封建契约下"出钱出枪者参政"的有机秩序——参考 1787 年制宪时期的美国、瑞士山谷自由民共同体、日耳曼自由市市民阶层。

### K-1.7.2 选民资格门槛——「钱或枪」择一逻辑

修订理由（邦联宪制起草委员会与稷下会盟院政策研究局联署核定）：

原条款要求纳税人资格与民兵服役资格同时满足，立意在于贯彻「出钱出枪者参政」之封建铁律。然实务上存在内在矛盾——燕山邦大学共同体、文化遗产法团、防务智库这类群体（见 K-8.1），其成员纳税且具专业能力，但令文化学者赴民兵名册挂名，是强迫其执行一个对其而言毫无实质意义的仪式。中世纪英格兰之 Borough 代表不需持弓，其代表资格来自行会与城市特许状，不来自个人武装服役。

双重门槛之逻辑可取，然「或」比「且」更具弹性。纳税或服役择一即足以体现封建铁律。为维持激励结构，纯纳税人门槛之税额要求高于纯民兵资格之税额要求。

唯有满足下列两项中之一项条件者，方为邦联与各邦的合格选民：

|     |     |     |
| --- | --- | --- |
| 路径  | 实质要求 | 适用群体类型 |
| **①** 纳税人路径（高税额门槛） | 在登记年度内向所属邦或邦联缴纳超过高门槛直接税（财产税、营业税、关税、过境税等）；公共救济受领者、单纯转移支付收入者不在此列。高门槛税额由各邦邦法规定，不得低于本邦平均民兵服役者之年综合贡献当量的 **1.5** 倍。 | 燕山邦大学共同体之资深教席、稷门特区航运公会高级合伙人、各邦地主豪绅与商团股东等 |
| **②** 民兵路径（低税额门槛 **\+** 服役） | 已在所属邦或法团的民兵名册（Militia Roll）注册在编，履行核心节点的武装保卫义务；同时缴纳基础税额（基础税额可显著低于纳税人路径之高门槛） | 永平邦矿业护卫队、上谷邦边境巡逻队、稷门特区商团武装、保定邦宗族民团、辽西邦防务承包人等 |

特别替代条款——文化与防务贡献认定：

燕山邦大学共同体、文化遗产法团、防务智库等特殊法团之成员，得依本邦内部章程，以\*\*「文化—防务贡献认定」\*\*替代民兵名册登记，但须满足下列两项条件之一：

在邦联或本邦防务智库连续登记服务三年以上，且其研究成果经历史权利法庭确认对邦联安全或宪制建设有实质贡献者；

持有该邦特许之文化遗产、知识产权、教育机构经营权，并对该法团承担长期治理责任者。

文化—防务贡献认定一律由所属邦邦议会主持的资格委员会出具，认定结果须报历史权利法庭备案，下院得依其内部章程对个案行使复核权。

### K-1.7.3 合格选民的典型形态

作为示意（非穷尽列举），下列群体构成本邦选民阶层的核心凝结核：

永平邦矿业护卫队成员（矿业重工 + 武装保卫）；

上谷邦边境巡逻队成员（边疆民兵 + 互市纳税）；

稷门特区商团武装成员（航运公会 + 商团自卫队 + 关税缴纳）；

保定邦宗族民团成员（宗族信托 + 水利共管 + 田赋）；

中山邦铁路商团护卫队成员（铁路法团 + 商业税）；

辽西邦防务承包人及其登记雇员（战略物资仓储 + 港口民兵）；

沧海邦盐业公会武装成员（盐业 + 海洋渔业 + 沿海民兵）；

邺邦水文协会与过境贸易商团成员（漳河水权 + 商税）；

燕山邦法团教师与学者（须同时在民兵名册或在邦联有显著文化—防务贡献）。

### K-1.7.4 不享有政治权利的群体

依本节条款，下列群体不享有邦联与各邦的选举权与被选举权，但其人身、财产、宗教、迁徙等私法权利受邦联宪制完整保护：

流民、流动人口、无固定居所者；

未在民兵名册登记或登记后失格者；

未达邦联税赋门槛者；

公共救济受领者（在领期间）；

依各邦习惯法判处剥夺荣誉权之人。

注：此类群体在政治上"乖乖在旁边交保护费"——即作为被保护对象履行义务、享受社会秩序，但不参与对秩序的塑造。这是封建契约下保护与被保护关系的本来形态，亦是对抗现代大众民主"搭顺风车的做题家通过选票寻租"之结构性弊病的根本机制。

### K-1.7.5 选民资格的两院差异化适用

下议院（法团院）选举——选民必须同时满足 K-1.7.2 两项门槛，且必须经由其所属法团（民兵单位、行会、公会、宗族联合会）行使选举权，不得以独立公民身份直接投票；

上议院（邦君院）产生——不经由公民直接选举，而由各邦内部最高权力机构任命或间接选举（见 K-1.3.2），故 K-1.7 门槛不直接适用，但各邦内部任命程序须遵循本邦习惯法确立的精英资格规则。

### K-1.7.6 选民资格的复核与升降

每三年由所属法团联同邦税务厅复核一次；

失去民兵资格或纳税资格者，自动暂停选举权直至恢复；

因军事荣誉、特殊财政贡献等可由历史权利法庭授予终身选民资格；

任何关于选民资格的争议，由历史权利法庭终审。

### K-1.7.7 制度类比与思想史定位

古典模型：罗马共和国百人队大会（Comitia Centuriata）——以装备等级与赋税单位组织投票；

中世近代模型：英格兰自由民选举权（freeholders）+ 民兵法（Militia Acts）；

建国初期美国模型：1787—1820 年代各州普遍施行的财产 **\+** 民兵服役双门槛选举权（在杰克逊式大众民主到来之前的封建—共和过渡期）；

思想史定位：施特劳斯式"古今之争"中的古代派立场——政治权利与德性、武德、对共同体的实质负担成正比，而非由抽象的天赋人权派生。

## K-1.8 外部秩序输入框架

修订理由（邦联宪制起草委员会与稷下会盟院政策研究局联署核定）：

原知识库海疆编（第七编）仅写渤海三方划界，未处理与海洋秩序输入方之条约关系。渤海是半闭海，出渤海即黄海、东海，对岸为美日韩势力范围。幽燕若不与外部海洋秩序挂钩，则邦联在大陆强权面前仍为孤立据点，邦联宪制之稳定缺一道法律保险。本章专门处理此一缺漏。

### K-1.8.1 外部秩序输入之必要性

邦联依秩序输入／输出诊断（劉仲敬學派分析法第六项）判断：大洪水后之东亚秩序窪地中，单一陆上强权之兴起足以钳制半闭海出口。若不向海洋秩序输出方建立条约通道，邦联将面临：

出海通道受制于单一陆权——即使渤海三方海界完整确立，黄海—东海航道仍受陆权钳制；

法律孤立化——本邦海商、离岸金融、国际仲裁等核心法律服务（见 K-9 第九编）无外部承认锚点；

军事备援空白——共同防御（原 K-1.4.5）仅依本邦民兵—法团武装，无外部均势保险。

### K-1.8.2 稷门特区国际仲裁锚点

稷门联邦特区开放为海洋法系国际仲裁中心，承担下列功能：

海洋法系仲裁中心：依《联合国海洋法公约》与英美海商法体系，为渤海—黄海—东海航运、保险、装卸、单位化协定等争议提供中立仲裁；

离岸金融与跨境信托：参照新加坡、香港模式，但司法主权归邦联；

国际条约存放与登记中心：邦联与外部缔结之一切条约存放于稷门，编号公开，供历史权利法庭检索。

稷门特区以此为锚点向外延伸条约网络——条约相对方愈多、愈分散，则单一大陆强权钳制邦联之物理可能性愈低。

### K-1.8.3 渤海—黄海海峡通道之国际化定性

渤海海峡（含老铁山水道）之国际化定性，系邦联抵制任何单一大陆强权垄断出海口之法律保险。

具体而言：

邦联与外部缔约方共同主张：渤海海峡为《联合国海洋法公约》第三十八条意义上之\*\*「用于国际航行之海峡」\*\*，享有过境通行权（transit passage）；

邦联反对任何邻邦（含鲁国、满洲国）以单方主权主张关闭该海峡；

任何关闭、限制、加价或差别待遇该海峡之行为，自动触发邦联与外部缔约方之协商机制。

### K-1.8.4 条约相对方之分散化原则

外部条约相对方应分散化，不得集中于单一海洋强权或单一区域集团。

参照荷兰联省共和国 17 世纪与英法葡西分别缔约之模式——分散化是封建邦联保持自主性的结构性保障，集中化则在事实上构成附庸关系。

|     |     |     |
| --- | --- | --- |
| 条约层级 | 相对方类型 | 典型内容 |
| 核心层 | 海洋法系国家 | 商航、仲裁互认、领事保护 |
| 次核心层 | 区域中等强权 | 反走私、反海盗、海洋环境合作 |
| 外围层 | 国际组织与跨国法团 | 仲裁规则、跨境信托、保险互认 |

### K-1.8.5 与陆上邻邦关系之分离原则

邦联与外部海洋秩序之条约关系，与邦联同陆上邻邦（晋国、豫国、鲁国、满洲国、蒙古国）之关系互相分离，不得交叉抵押。

即——邦联不得为换取陆上邻邦之让步而牺牲海洋条约通道；亦不得以海洋盟友之名义干预陆上邻邦之内政。两套关系平行运转，分别由不同部门主导：

陆上邻邦事务：稷下会盟院政策研究局陆界处 + 外交部条约审议处陆约科；

海洋外部秩序：外交部条约审议处海约科 + 稷门特区海事仲裁庭。

### K-1.8.6 紧急状态下之外部援助请求

邦联在紧急状态下（依 K-1.4.2a 紧急行政授权机制）得请求外部海洋秩序输入方之援助。请求须经下列程序：

首席执政官以紧急行政令提出请求；

上院以三分之二多数追认；

援助之内容、规模、期限须公告并存放稷门档案；

援助期满，外部部队及装备一律撤出，不得形成长期驻留。

## K-3.5 矿产共管

太行东麓井陉—峰峰矿区煤炭带：依"山脊归属国享有，山麓开采国征税"的共管模式处理——经济权益与军事实控分离。

## K-3.6 邯新晋语过渡带

邯郸西部、安阳林州一带存在晋语"邯新片"东延区域。该区域设为 **"**上党—邯郸语言文化自治走廊**"**，通过历史权利法庭裁决而非公投机制确定归属，保障双重文化权利，但不以民族语言边界取代山川主权线。

# 第五编 · 北疆：燕山—阴山生态边界（与蒙古国分界）

## K-5.1 核心原则：胡焕庸线主权化

边界沿燕山—七老图山—努鲁儿虎山山脊及坝上高原南缘，大致与年均 **400mm** 等降水线重合（胡焕庸 1935 年所描绘的农耕—游牧生态硬边界）。

归入幽燕版图后，对蒙古族聚居乡镇授予自治权；

历史上为清代皇家牧场；

归属幽燕，设立生态缓冲保护区；

### K-6.2.1 辽西走廊实控分期推进时间表

修订理由（邦联宪制起草委员会与稷下会盟院政策研究局联署核定）：

原 K-6.2 与 K-6.3 述及大凌河前出之战略必要性，然未处理实控线之分期推进问题。原 K-6.3 自承「葫芦岛、锦州处于敌火覆盖范围」即满洲国若不承认大凌河中线，则此前出线之维持成本极高。大洪水后之秩序窪地中，邦联在常备海军尚未成形之前，将大凌河前出线作为建国第一天即能维持之实控线，是财政黑洞。

# 第十编 · 疆界三大铁律（综评）

## K-10.1 第一铁律：山川为界，不依民族

西部太行、北部燕山均以自然分水岭为主权线，辅以历史权利法庭裁决处理族群过渡带。剔除威尔逊式公投机制，确保边界的地理稳定性高于选举结果的偶然性。

典型应用：

邯新晋语过渡带 → 文化自治走廊，主权依山川；

坝上草原 → 历史权利法庭 + 蒙古族特许自治；

沧州—德州 → 古黄河故道为水文边界。

## K-10.2 第二铁律：水权即治权

对漳卫水系枢纽（四女寺）、渤海海峡（老铁山水道）乃至南水北调受水节点的物理控制，构成本邦在所有南部边界谈判中执行裁决的实质能力基础。

典型应用：

幽豫边界谈判筹码 = 四女寺 + 漳卫调水节点；

幽鲁海上谈判筹码 = 渤海西—北港口弧线 + 庙岛群岛过境通行权；

与豫国订《科罗拉多式水权协定》防资源政治化。

## K-10.3 第三铁律：渤海是本邦的内湖

从辽西走廊大凌河口到歧口，再到天津滨海——幽燕对渤海西岸与北岸的控制，使渤海在地缘逻辑上趋近于本邦的\*\*"内湖"而非共享海域\*\*。任何邻邦对本邦出海通道的钳制，在物理上均无从实现。

典型应用：

方案 A 全段纳入辽西走廊 = 渤海北岸制海权前沿；

港口弧线（津—骅—唐—葫—锦）= 完整掌握渤海西北象限；

渤海三方海界 + Tripoint 灯塔 = 国际法地标化的内湖结构。

# 第十一编 · 邻邦秩序生产能力评估

编纂理由（邦联宪制起草委员会与稷下会盟院政策研究局联署核定）：

原 K-2.4 仅写邻邦地理分界，未处理各邻邦之秩序能力评估。然各邻邦在大洪水后之状态——是费拉化烂透还是有一定凝结核——直接决定本邦之边界是静态协议还是需要动态防御。本编依劉仲敬學派分析法第六项「秩序输入／输出诊断」，对五邻邦作出基线评估，作为外交部条约审议处与各邦自治议会跨邦协调办公室之共同参考。

本编评估为基线诊断，应每三年由稷下会盟院政策研究局更新一次。

## K-11.3 边界处理策略之总原则

依本编基线评估，边界处理策略分三档：

静态协议：邻邦秩序输入依赖度高、凝结核弱时，本邦以物理控制力为筹码，以协议方式锁定边界——主要适用于豫国南界；

半静态协议：邻邦秩序状态中等时，以协议为主、军事在场为辅——适用于晋国西界、鲁国东南界；

动态防御：邻邦秩序具备凝结核与一定武德、且其行动具有相当不确定性时，本邦须保持军事弹性 + 分期推进——主要适用于满洲国东北界。

## K-11.4 评估之更新与异议机制

每三年由稷下会盟院政策研究局组织重新评估；

任何邦邦议会得就涉及本邦之邻邦评估提出异议，由历史权利法庭复核；

重大邻邦事件（政权更替、内战、瓦房店化加速）之后，应立即启动专项评估而不待三年期满。
