# The Flag of the Yuyen Pohai  Confederate Republic — Official Description

> source note_id: `1911614942583872376`  
> topic: `40D9VmeJ`

紫白对称，山鹰居中，北山南水承之于上下。本邦联以此旗示于万邦：吾国法统古老，吾国疆界自然，吾国气质节制，吾国共同体由习惯法与诸成员之相互信契而成。

本邦联国旗由两道紫色横带、白色旗地与中央紫色徽记三部分构成。紫白二色与上下对称之布局，承载本邦联之精神传承、自然禀赋与共同体守护三义。

紫为本邦联之国色，其义有三。其一，紫为推罗紫（Tyrian purple）之古色，希伯来会幕之帷帐与地中海腓尼基商邦之染料皆以此色为标志，本邦联以紫为色，标明其精神宪制资源与古典经法传承同源，亦与海洋商业文明同源。其二，紫为中华古典之北辰色，紫微垣居天之中央，象征秩序之中枢而非武力之征服，本邦联以紫为色，宣示其法统生于秩序之自然，非生于征服之偶然。其三，紫为节制之色，无赤色之激越，无黑色之肃杀，无黄色之骄矜，本邦联以紫为色，标明其精神气质崇尚克制审慎而非张扬竞胜。

白色为旗地之色。白者，习惯法传承之净也，亦邦联诸成员相互信契之净也。中华古典以素白为礼之始、为契之诚，希伯来经法亦以白为洁净归一之象。旗地以白承紫，宣示本邦联一切公共生活皆建于古老习惯与相互信契之上，非建于一时之激情或权力之独断。

上下两道紫带，象征本邦联之南北两条自然生命线。上带为北疆之燕山—阴山弧线，本邦联依此弧线区分定居农耕文明圈与草原游牧文明圈，年均四百毫米等降水线沿此而过，胡焕庸线之物理实体即在于此，本邦联以此为北方屏护之天然脊梁。下带为南疆之漳卫—海河水系，本邦联依此水系灌溉冀中平原、养育稷门门户、串连八邦腹地，水权即治权之古训亦由此而生。两带等宽，宣示北山与南水于本邦联之意义平等不偏；中间留白，则诸邦各依习惯法自治之广袤腹地也。

中央徽记取自战国时代中山国（State of Zhongshan, 5th–3rd century BCE）瓦钉饰纹样，经现代改编而成。中山国本为白狄所建之非华夏诸侯，立国于太行东麓山陉之间，其青铜工艺自具山地族群之审美——不取周礼之圆熟雍容，而取山陉之峻削对称。河北平山中山王厝墓所出此式瓦钉饰，原为宫室屋脊或檐部之装饰构件，正面铸双鸷鸟头分朝两向、中央承一三峰山形之纹样，两侧再以双月形勾连环抱，整体呈现高耸对称、内收沉敛之轮廓。双鸟与山峰之组合，旧释为山神使者守望国门，新释为山脊之上观天测象者，两说今皆可并存，然其守望山陉、护卫家国之共同意指，二千余年来未有易改。本邦联取此古器为旗心纹样，非仅取其形之古，亦取其义之合——双鹰头分朝两向，一警陆疆，一警海疆，鹰为警戒守护之鸟而非攻伐扩张之鸟；中央山峰为太行山主脊之象征，本邦联西界以分水岭为界，山川为界、不依民族之立国铁律由此山峰所托；整体形制取自二千余年前中山国之古器物，标明本邦联法统不创自一时之激情，而生于诸夏古典之深沉传承。
